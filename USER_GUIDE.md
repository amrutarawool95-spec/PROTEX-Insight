User Guide
Project scope
This guide describes the intended use of the PROTEX-Insight interface based on the available project screenshots and description. The exact controls may differ in the running application.
1. Protein Explorer
Open the protein exploration area.
Select or enter a protein structure identifier.
Confirm the protein name, chain and structural metadata.
Inspect the residue sequence or structure view, if available.
Check which ligands, ions and waters are associated with the selected structure.
For the documented example, the target is EGFR structure PDB 1M17. Verify the selected chain and ligand before interpreting any downstream results.
2. Ligand analysis
Select the ligand of interest.
Verify its chemical identity and structure.
Review available molecular descriptors.
Inspect reported contacts or interactions.
Confirm that all displayed properties belong to the selected ligand.
Important: a chloride ion, crystallographic additive or other small molecule must not be mistaken for the drug ligand. Check ligand identifiers carefully.
3. Molecular docking
Before interpreting a docking result, identify:
Receptor structure and chain
Ligand identity
Receptor and ligand preparation procedures
Binding-site centre and dimensions
Docking software and settings
Number of poses and scoring output
Treat the score as a computational estimate. Inspect the pose and its chemistry rather than relying on a single number.
4. Mutation investigation
When reviewing a mutation, check the reference sequence, residue numbering, variant identity and evidence source. Distinguish sequence annotation from structural modelling and experimental functional validation.
5. Saving and reporting
Save the input identifiers, settings and raw outputs with each analysis. A screenshot is useful for communication, but it is not a substitute for the underlying files and logs needed to reproduce a calculation.
